# 迭代路线图(Roadmap)

> 本文档只做**前瞻规划**,不是进度真源。每期开工时,把对应任务搬进根目录 `PLAN.md` 追加里程碑段,
> 进度以 PLAN.md 的复选框为准。任务状态:`[ ]` 未开工 / `[~]` 进行中 / `[x]` 完成。
>
> 规划原则:每期独立可交付;标注环境依赖(标注 ⚠️环境 的项需要用户提供对应条件才能验证,
> 无环境不排期);质量与体验优先于堆功能。

## v0.5 体验与质量(2026-09-17 全部完成)

**目标**:把 M1–M4 已有能力打磨到"敢给团队日常用"的水平,不新增依赖环境。

- [x] 配置批量暂存区(staging)
  - 现状:每保存一次配置就开一次事务 + 一次 reload,连续调整时 reload 频繁
  - 目标:编辑操作先进入"待提交清单"(跨对话框累积),页面常驻入口显示待提交数量;
    提交前展示操作列表摘要;一次事务批量应用,只触发一次 reload;支持逐条移除与一键清空
  - 2026-09-17 v0.5 完成:真机走查通过,实测多操作合并为 1 次快照 + 1 次 reload;
    过程中发现 dataplaneapi v3.4.3 不支持 backend ACL 写入(405),UI 已下线该入口
- [x] 文本级 diff 预览
  - 现状:提交前只有字段级摘要
  - 目标:暂存区提交前,通过事务内 raw 配置与当前 raw 生成 unified diff 高亮展示(M3 已具备事务内读取能力)
  - 2026-09-17 v0.5 完成:新增 dataplane RawConfigTx + POST /config/preview(预览事务不提交),
    暂存面板 diff 视图绿增红删、未变段折叠,真机验证与提交结果一致
- [x] 后端自动化测试
  - dataplane 客户端单测:202/201/204 状态码语义、/v3 字段差异(weight 数字、name 字段)回归
  - BFF API 集成测试:复用 `deploy/dataplaneapi/local-e2e` 容器跑真实链路
  - 2026-09-17 v0.5 完成:单测 + 进程内集成(fake dataplaneapi,零新依赖)+ 容器级集成
    (local-e2e 已 compose 化,make test-integration,容器不可达自动 skip)
- [x] E2E 冒烟测试(Playwright)
  - 登录 → 实例增删 → 配置读取 → 运行时上下线 → 模板创建 → 回滚,覆盖核心链路
  - 2026-09-17 v0.5 完成:make e2e,自动编排容器 + 独立 DB 后端 + vite dev,实测 1 passed
- [x] 多实例体验
  - 侧边栏「配置管理」在多实例时弹出实例选择器(当前固定进第一个实例)
  - 监控聚合总览:单页展示全部实例健康状态(UP/DOWN 计数、QPS 汇总),点击下钻
  - 2026-09-17 v0.5 完成:实例选择器(附健康点)+ /monitoring 总览页(集群分组、聚合卡、下钻),
    双实例(rainyun-rcs + local-e2e 容器)实测通过
- [x] 小项打包:前端构建分包(消除 chunk 500k 警告)、列表分页、暗色模式
      (2026-09-17 v0.5 完成:路由懒加载后入口 448kB 无警告;暗色三态切换;审计/服务器表分页)

**验收**:连续做 5 处配置修改只触发 1 次 reload;`go test ./...` 与 E2E 冒烟进 Makefile;
两个以上实例时选择器正常工作。

## v0.6 运维与可观测

**目标**:从"管理配置"扩展到"运维保障",具备告警与巡检能力。

- [ ] 配置快照定时抓取:后台任务按周期(可配)自动同步节点配置为快照,漂移可见
- [ ] 告警通知:reload 失败、backend 全 DOWN、连通性探测失败时推送 Webhook
  (飞书 / 钉钉 / 企业微信机器人,可配置)
- [ ] 节点 Prometheus 探测:实例详情显示节点 8404 /metrics 是否可访问,未接入时给出接入指引
- [ ] 会话管理:JWT 刷新与主动吊销(改密 / 删除用户后强制下线)
- [ ] 审计日志增强:时间范围过滤、导出 CSV

**验收**:人为制造 reload 失败能收到通知;改密后旧 token 失效。
